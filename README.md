# نبرة · Nabra
منصة صوت عربي: نطق بالإماراتي والسعودي والكويتي والمصري والإنجليزي، تفريغ صوتي يكشف اللهجة، تنقية صوت على الجهاز (RNNoise)، ووكيل صوتي «رفيج».

- الواجهة: موقع ثابت (PWA) على GitHub Pages.
- الذكاء: Supabase Edge Function (`supabase/functions/ramsa`) تستدعي Google Gemini؛ المفتاح سرّ على الخادم فقط.
- `vendor/rnnoise.js`: @shiguredo/rnnoise-wasm (Apache-2.0، انظر vendor/LICENSE).

## الهوية: نَبرة (Nabra)
الاسم السابق «رمسة». الشعار: حرف «ن» هندسي (الوعاء) ونقطته تتحول إلى نبضة صوت. الملفات: `icons/logo.svg` (أساسي)، `logo-light.svg`، `logo-dark.svg`، `mark.svg` (أحادي اللون، currentColor)، و PNG: favicon 32/64، apple-touch 180، PWA 192/512 و 512 maskable. نسخة متحركة في الواجهة الرئيسية (تحترم reduce-motion).
الرابط الحالي https://almarar88.github.io/ramsa/ ما زال يعمل (المستودع لم يُعَد تسميته حتى لا ينكسر الرابط).

## المكالمة المباشرة (Gemini Live)
- الخادم يصدر توكن مؤقت (استخدام واحد، دقيقتين لبدء الجلسة) مع نص النظام والأدوات مقفلة على الخادم؛ المفتاح الحقيقي لا يصل للمتصفح.
- المتصفح يفتح WebSocket مباشر: مايك مفتوح طوال المكالمة (echoCancellation/noiseSuppression/AGC) بث PCM 16kHz، والرد صوت 24kHz مُجدول بدون فجوات، مقاطعة فورية (محلية + `interrupted` من الخادم)، كشف نهاية الكلام على الخادم (~450ms)، ضجيج خط خفيف.
- الأدوات (حجز/تذكرة/طلب/معاودة) تنفذ عبر `cc_action` على الخادم؛ التحويل وإنهاء المكالمة على الجهاز.
- عند فشل البث يرجع تلقائيًا للمحرك القديم (مع رد فوري «تمام، لحظة»).
